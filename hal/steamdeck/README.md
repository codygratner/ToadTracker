# Valve Steam Deck (SteamOS x86_64) Hardware Abstraction Layer
Target: Valve Steam Deck running SteamOS 3.x (Linux x86_64).
Display: 1280x800 display, 3x integer scaling (720x720) with lateral utility sidebars.
Controller: 1:1 hardware mapping to M8/ToadTracker 8-button standard + haptic trackpad jog wheels + rear grip buttons (L4/L5/R4/R5).
Audio: Native low-latency PipeWire / ALSA.
