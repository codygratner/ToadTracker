# ToadTracker Glossary

- **Song**: Top-level composition.
- **Chain**: A sequence of phrases.
- **Phrase**: A musical pattern.
- **Instrument**: The sound generator.
- **Table**: Parameter automation.
- **P-Lock**: Parameter lock.
- **HAL**: Hardware Abstraction Layer.
- **AudioThread**: The real-time audio thread.
- **SPSC FIFO**: Single-Producer Single-Consumer FIFO.
