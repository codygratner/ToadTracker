## ⚡ Core Operational Protocols (Executive Summary)

1. **Multi-Tier Model Economics (Pro vs. Flash):**
   - **Tier 1 (Pro High):** High reasoning capacity. Reserved strictly for deep DSP differential equations, non-linear waveshaping algorithms, SIMD optimization, and complex architectural synthesis.
   - **Tier 2 (Flash High):** Fast, sustainable daily driver. The universal default for drafting plans, writing JUCE UI components, and executing build phases.
   - **The "Pro Sanity Gate":** Draft in Flash High $\to$ 1-turn Pro High sanity audit $\to$ execute build on Flash High.
2. **The Tri-Engine Subagent Pattern:**
   - Deploy 2 exploratory subagents (`explore`, Flash) alongside 1 adversarial subagent (`contrarian`, Flash) to derive the pragmatic 80/20 middle ground.
3. **The 2-Strike Factory Escalation:**
   - Klang Industries has up to 2 attempts to resolve a compilation or test failure on Tier 2. If still failing, it hard-pauses, recommends a Tier 1 upgrade, and waits for user confirmation.
4. **The Asymmetric Sidecar Split:**
   - Keep chat responses terse and conversational (1–3 sentences); render rich diagrams, tradeoff tables, and mockups inside the N'kai sidecar canvas.
